# Learnings

Post-investigation findings, root cause analyses, and research conclusions. Each entry documents what was discovered, why it matters, and what changed as a result.

## Convention

Each learning is a numbered markdown file: `{NNN}-{title}.md`

### Template

```markdown
# {NNN}: {Title}

Date: YYYY-MM-DD
Area: {feature or subsystem}
Trigger: {what prompted the investigation}

## Problem

What was observed.

## Root Cause

What was actually wrong.

## Fix

What changed.

## Lessons

What we learned that applies beyond this specific fix.
```
