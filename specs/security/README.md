App-level security documentation.

- `SECURITY_SCAN_REPORT.md` — Security scan findings and remediation

## Per-Feature Threat Models

Each feature has its own `threat-model.md` under `specs/features/{domain}/{feature}/`.
These cover feature-specific attack surfaces and reference NFR security requirements from `specs/nfr/security.md`.
